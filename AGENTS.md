# AGENTS.md

Antes de tocar nada, leé estos archivos, en este orden:

- `CLAUDE.md`: reglas del repo, estructura y cómo sumar un paso.
- `DESIGN.md`: especificación del archivo exportado y documento vivo del proyecto. Si no coincide con el código, gana `DESIGN.md`: avisá la diferencia.
- `PLAN.md`: tareas del plan. Hacé solo la que te pidan y marcala al terminar.

Comandos: `npm run dev`, `npm test`, `npm run typecheck`, `npm run build`. Antes de dar una tarea por terminada: `npm run typecheck && npm test`.
